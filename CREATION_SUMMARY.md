## 🔄 Customization Examples

### Change Theme Color
Edit `codeverse-layout.jsp`:
```css
--primary-gradient: linear-gradient(135deg, #YOUR_COLOR 0%, #YOUR_COLOR 100%);
```

### Add New Navigation Item
Edit sidebar in `codeverse-layout.jsp`:
```jsp
<li><a href="/your-path" class="<c:if test="${param.page == 'yourpage'}">active</c:if>">
    <i class="fas fa-icon"></i> Your Page
</a></li>
```

### Modify Form Fields
Copy form section and edit:
```jsp
<div class="form-group">
    <label for="field" class="form-label">Your Label</label>
    <input type="text" class="form-control" id="field" name="fieldName">
</div>
```
